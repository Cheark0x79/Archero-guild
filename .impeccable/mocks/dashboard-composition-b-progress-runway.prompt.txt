Light cool-gray main canvas, near-black blue-slate navigation, one cyan accent, amber only for attention, red only for urgency. Crisp workhorse humanist sans, dense but calm, strong numeric hierarchy, thin separators, minimal elevation, modest 6–8px corners. Use continuous bands and fields rather than generic dashboard card soup.
